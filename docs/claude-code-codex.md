# 接入 Claude Code 和 Codex

同一个手机 App 也能管电脑上的 **Claude Code** 和 **Codex CLI**。离开电脑时，它们的确认请求会发到手机上批准，任务完成会提醒你；你还能在手机上看会话记录，并从手机继续对话。

原理：两者都支持"生命周期钩子"（hooks）。装好之后，它们每次开始会话、收到指令、要你确认、完成任务时，都会调用 `tools/pager-hook.mjs`。这个脚本把事件转给电脑上 DSH 里的 dsh-pager 插件，再把插件的答复交回去。

## 安装

前提：dsh-pager 插件已经在 DSH 里运行（见 README）。钩子通过 DSH 的端口与插件通信。

```bash
node tools/install-hooks.mjs claude     # 写入 ~/.claude/settings.json 的 hooks
node tools/install-hooks.mjs codex      # 写入 <CODEX_HOME>/hooks.json
```

- 只合并、不覆盖：你原有的钩子都保留；重复运行只会更新我们自己的条目。
- 写入前会把原文件备份为 `<文件>.bak-dsh-pager-<时间>`。
- **Codex 只运行你信任过的钩子**：装好后打开 Codex，输入 `/hooks` 确认信任一次。
- 卸载：`node tools/install-hooks.mjs claude --uninstall`（Codex 同理）。
- 只看效果不写入：加 `--dry-run`。

钩子是"失败即放行"的：DSH 没开、插件没装、网络出错时，它什么都不做，工具照常运行。

## 确认请求发到哪里

在手机首页的"Claude Code / Codex"区，或会话菜单里切换：

| 模式 | 行为 |
|---|---|
| **自动**（默认） | 电脑锁屏，或 3 分钟没有键盘鼠标操作时，确认请求发到手机；一旦有人碰电脑，请求立刻交还电脑上的确认框 |
| 总是先问手机 | 先发到手机；20 分钟没回应再交给电脑 |
| 只在电脑上确认 | 不发到手机，只在电脑上弹确认框 |

- 在手机上可以"允许""拒绝"。Claude Code 还多一个"允许并记住"：本次会话里同类操作不再询问。
- 在锁屏通知上点"允许"，Android 12 及以上会先要求解锁。
- 从手机发起的那一轮，确认请求一律发到手机，因为电脑前没人。
- "是否在电脑前"通过 Windows 的空闲时间和锁屏状态判断，只在本机读取，不上传。其他系统上判断不了，"自动"模式会按"在电脑前"处理。

## 在手机上看和继续

- 首页"Claude Code / Codex"区会列出最近 7 天的会话。这里的数据来自它们自己的会话文件，所以装钩子之前的会话也在：
  - Claude Code：`~/.claude/projects`
  - Codex：`<CODEX_HOME>/sessions`
- 点开能看到提问、回复、每个工具一行和结果；正在看的会话有新内容时自动刷新。菜单里的"项目文件"可以用结果查看器浏览该会话的目录。
- **从手机继续**：在会话底部发消息，电脑会在后台运行 `claude -p <消息> --resume <会话>` 或 `codex exec resume <会话> <消息>`。
  - 这一轮里的确认请求发到手机；完成或出错都会通知你。
  - 消息作为一个整体参数传给命令，不经过 shell，所以消息里的特殊字符不会被当成命令执行。
  - 如果电脑上这个会话的窗口还开着，它看不到手机上继续的内容。建议在电脑上关掉它，或之后用 `--resume` 重新打开。

## 已知限制

- 从手机继续对话，依赖电脑上命令行工具本身能用：Claude Code CLI 要处于登录状态，Codex CLI 要支持你配置的模型。命令行报错时，手机上会直接显示它的原话。
- 会话记录只读取文件末尾 4 MB（很长的会话只显示最近部分）。
- Claude Code 的"子代理"对话不在主会话里显示。

## 排错

| 现象 | 查什么 |
|---|---|
| 手机上看不到 Claude Code / Codex 区 | 最近 7 天没有会话文件；或插件不是最新 |
| 离开电脑后确认请求没到手机 | 模式是否为"自动"或"总是先问手机"；`~/.dsh-pager/hook.json` 是否存在（插件启动几秒后写入）；Codex 是否已在 `/hooks` 里信任 |
| 手机发消息后提示 401 / 登录过期 | 在电脑终端运行 `claude`，输入 `/login` 重新登录 |
| 手机发消息后提示需要新版本 | 升级 Codex CLI（`npm i -g @openai/codex`） |
