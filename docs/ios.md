# iPhone / iPad

iPhone 用的是网页版：在 Safari 里把 `/m/` 添加到主屏幕，就是一个全屏 App。界面和安卓版完全一样，锁屏提醒走网页推送（Web Push）。

要求：
- iOS / iPadOS **16.4 或更高**（网页推送从 16.4 开始支持）；
- 能从手机访问到你电脑上的 `/m/`，而且是 **https** 地址（网页推送只在安全连接下可用），见 [remote-access.md](remote-access.md)。

## 安装

1. 用 **Safari** 打开 `https://你的网关地址/m/`，按网关要求登录一次。
2. 点底部的"分享"按钮，选**添加到主屏幕**，名字保持"DSH"即可。
3. 回到主屏幕，从新出现的 DSH 图标打开。

> 如果登录后看到的是 DSH 的电脑版界面：从主屏幕图标打开时会自动跳回手机版（插件在电脑版页面里放了一小段跳转脚本，只对"已安装的网页 App"生效，普通浏览器标签页不受影响）。

## 开启锁屏提醒

1. 从**主屏幕图标**打开 DSH。在 Safari 标签页里没有这个选项，这是 iOS 的限制。
2. 点左上角的连接状态，再点**开启锁屏提醒**，在系统弹框里选"允许"。
3. 点**锁屏提醒已开启**，会发一条测试推送，几秒内锁屏应该收到。

之后会收到这几类提醒，内容和安卓版一样：

| 事件 | 提醒 |
|---|---|
| 工具需要审批 | "需要你确认 · 会话名"，点开进会话批准或拒绝 |
| Agent 在提问 | "DSH 在问你 · 会话名" |
| 任务完成 | 会话名 +"已完成 · 耗时"和回复开头 |
| 出错 | 会话名 +"运行出错：…" |

和安卓版的区别：iOS 的网页推送不支持通知上的按钮，审批要点开通知，在 App 里完成。

## 隐私与原理

- 推送经过苹果的推送服务转发，但内容是**端到端加密**的（RFC 8291）：只有你这台 iPhone 能解密，苹果看不到会话名和内容。
- 服务端签名密钥和已登记的设备，保存在电脑上的 `~/.dsh-pager/`（`vapid.json`、`push-subs.json`），不在代码仓库里。
- 发推送的是你家里的电脑，它要能访问 `web.push.apple.com`。这是苹果推送服务的一部分，一般网络都能访问；万一访问不了，只是收不到推送，其他功能不受影响。
- 删掉 `~/.dsh-pager/push-subs.json` 或在 App 里点"关闭锁屏提醒"，就不会再推送。

## 排错

| 现象 | 处理 |
|---|---|
| 找不到"开启锁屏提醒" | 必须从主屏幕图标打开，而且系统版本是 iOS 16.4 以上 |
| 提示"通知权限被拒绝了" | 设置 → 通知 → DSH → 允许通知 |
| 测试推送提示"推送服务返回 4xx" | 在 App 里关闭再重新开启锁屏提醒；还不行，删掉主屏幕图标重新添加 |
| 平时收不到，测试能收到 | 检查专注模式 / 勿扰模式是否屏蔽了 DSH |

实测情况：推送链路（加密、签名、推送服务投递、页面后台服务弹出通知）已在电脑上的 Edge 浏览器里端到端验证；在真实 iPhone 上的验证等有设备时补上。
